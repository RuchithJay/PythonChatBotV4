# Python ChatBot 🤖💬

A modular, configurable chatbot written in Python with external JSON configuration.

## Features

- **Natural conversation flow** with greetings, questions, and goodbyes
- **External configuration** - All responses stored in JSON files for easy customization
- **Personalization** - Remembers user's name and uses it in responses
- **Context awareness** - Handles follow-up questions and conversation flow
- **Multiple response categories** - Tech jokes, compliments, fun phrases, and more
